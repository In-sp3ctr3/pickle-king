# Disposable ticket checkpoint template

Copy into ignored `.work/active/<ticket>/STATE.md` only after reading current Linear, Git and PR state. It is a continuation aid, never authority.

| Field                                             | Value |
| ------------------------------------------------- | ----- |
| Ticket and Linear URL                             |       |
| Current branch, HEAD and PR                       |       |
| Phase, risk and scope                             |       |
| Last verified time                                |       |
| Current plan and exact next action                |       |
| Changed files and pre-existing residue            |       |
| Completed checks with revision and skipped checks |       |
| Review findings and rechecks                      |       |
| Blockers and authoritative links                  |       |
| Release/flag/rollback decision if applicable      |       |

Reconstruct this table when absent. Never store secrets, full chat logs or duplicate status claims here.

## Engineering OS Feedback

Record the opaque ledger reference; latest assessment ID or `unassessed`; observation IDs with concise classification/disposition; and unresolved immediate signals. Explicit `none` is distinct from missing feedback and does not close earlier observations. Do not store raw evidence, local paths, secrets, or transcripts.
