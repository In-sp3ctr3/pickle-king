# Gates

| Gate          | Acceptance                                                                               |
| ------------- | ---------------------------------------------------------------------------------------- |
| Behavior      | Share copy is truthful; Quick Match records once and returns to setup.                   |
| Responsive    | No label, node, timing control, dialog, or preview overflow at the contracted viewports. |
| Exports       | Every format has the contracted dimensions, safe area, and complete bracket content.     |
| Accessibility | Focus, labels, live errors, 48px targets, and reduced motion remain valid.               |
| Quality       | `npm run check`, `npm run format:check`, Vinext, PWA, browser, and visual gates pass.    |
| Delivery      | Verified squash PR is merged and the exact `main` commit is deployed through Sites.      |
