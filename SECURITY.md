# Security Policy

## Supported version

Security fixes are applied to the latest code on `main`.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub’s private vulnerability reporting
for this repository. Include reproduction steps, affected versions, impact, and
any suggested mitigation.

You should receive an acknowledgement within seven days. We will coordinate
disclosure after a fix is available and credit reporters who want attribution.

## Scope

Pickle King has no backend and intentionally keeps names and scores in browser
storage. Reports about data transmission, unsafe persistence parsing, service
worker cache poisoning, dependency compromise, or script injection are welcome.
